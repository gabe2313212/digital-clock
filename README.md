# 🕐 World Clock - Digital Clock with Multiple Time Zones

A beautiful, real-time digital clock application that displays current time across multiple time zones simultaneously. Perfect for tracking time across the globe!

## Features

✨ **Multi-Timezone Support**
- Display clocks for multiple time zones at once
- Search for any timezone by city or region name
- Quick-add buttons for popular cities

🕰️ **Dual Display Format**
- 24-hour digital time display
- 12-hour format with AM/PM indicator
- Analog clock representation

📅 **Detailed Time Information**
- Current date with day of week
- UTC offset for each timezone
- Real-time updates every second

🎨 **Beautiful UI**
- Modern gradient design
- Smooth animations
- Responsive layout (desktop, tablet, mobile)
- Card-based interface

💾 **Local Storage**
- Your selected timezones are saved automatically
- Preferences persist across sessions

## How to Use

1. **Quick Add**: Click any city button (New York, London, Tokyo, etc.) to instantly add that timezone
2. **Search**: Type a city or timezone name in the search box and click "+ Add Timezone"
3. **View**: See digital time, 12-hour format, analog clock, and date for each timezone
4. **Remove**: Click "Remove" on any card to delete it
5. **Save**: Your selections are automatically saved to your browser

## Local Storage

Your clock preferences are automatically saved to browser LocalStorage:
- Active timezones list is stored
- Loaded automatically when you revisit
